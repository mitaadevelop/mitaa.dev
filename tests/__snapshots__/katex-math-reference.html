Mathematics on this blog is rendered with KaTeX at build time. There is no client-side JavaScript involved: by the time a page reaches your browser the formulas are already plain HTML, with a MathML copy alongside them so screen readers can read them out.

This post is both a reference and a test fixture. It is deliberately long and split across thirteen chapters, so it also exercises the chapter pagination this blog uses for longer reports. Use the arrow keys to move between chapters.

1How to write math here

There are three ways to write a formula.

Inline math goes between single dollar signs and flows with the text: E=mc2E = mc^{2}E=mc2, or ε>0\eps > 0ε>0, or the claim that ∀x∈R:x2≥0\forall x \in \R : x^{2} \ge 0∀x∈R:x2≥0.

Display math goes between double dollar signs on their own lines, with a blank line before and after:

∫−∞∞e−x2  dx=π\int_{-\infty}^{\infty}e^{-x^2}\,\dd x = \sqrt{\pi}∫−∞∞​e−x2dx=π​

A fenced math block does exactly the same thing and is the safer choice when a formula contains a dollar sign, or when you are writing inside a list:

lim⁡n→∞(1+1n)n=e\lim_{n \to \infty}\left(1 + \frac{1}{n}\right)^{n} = en→∞lim​(1+n1​)n=e

1.1The one rule that bites everyone

$$…$$ written on a single line is not display math — it is inline math with doubled delimiters. That matters because several commands only work in display mode. Writing $$x \tag{1}$$ all on one line produces the error:

KaTeX parse error: \tag works only in display equations

Put the $$ on their own lines, or use \[ … \], and it works.

1.2Escaping rules

Math is the one place in a post where LaTeX’s own escaping rules apply unchanged, because the content between the delimiters is handed to KaTeX verbatim. These are the rules worth knowing.

Situation What to write
A literal dollar amount \$5 to \$10, or the text between them becomes math
A percent sign \% — a bare % starts a comment and eats the rest of the line
A hash \# — a bare # marks a macro parameter
An ampersand outside math \& — a bare & separates table columns
An underscore outside math \_
Math inside a tabular cell Keep it to a single expression; an & inside it would end the cell
Anything inside verbatim or lstlisting Nothing. Listing contents are never interpreted
Math in \title or \excerpt Don’t. Metadata never goes through the math pipeline

So a price is written \$5 to \$10 and renders as $5 to $10, while $5 to $10 would silently become math.
