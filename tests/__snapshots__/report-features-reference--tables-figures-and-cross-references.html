Both get a label with \label{}. Point at them with \Cref{}, and the word and number fill themselves in. Plain \ref{} prints the number alone — Table 1 — exactly as it does in the PDF:

  • The theorem above is Theorem 2, resting on Definition 1.

  • The bench is shown in Figure 1.

  • \cref{} writes the word in lower case — see figure 1 — and hyperref’s \autoref{} reads like \Cref: Table 1.

Cross-references work across chapters too: Table 2 is defined three chapters further on, and the link still resolves — the whole post is rendered before any page is served, so a forward reference is no different from a backward one.

How a key is resolved

\ref{} and \cite{} are resolved the same way: a key that names a \label{} becomes a cross-reference, and anything else is looked up in the bibliography. There are no reserved prefixes — fig-setup, bench and setup are all fine. If a label and a bibliography key collide, the label wins.

A reference that points nowhere is not silently dropped — it renders visibly, like [?fig-doesnotexist], so a broken link is caught in review rather than in production.
