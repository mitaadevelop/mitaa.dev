\section{Design Philosophy}

For my portfolio, I wanted three things:

\begin{enumerate}
  \item \textbf{Dark UI} — easier on the eyes, modern feel
  \item \textbf{Minimalistic} — content-first, no clutter
  \item \textbf{Fast} — instantaneous page loads
\end{enumerate}

\section{Tech Stack Decisions}

\begin{itemize}
  \item \textbf{Next.js 15} with App Router for server components and routing
  \item \textbf{Tailwind CSS} for rapid, consistent styling
  \item \textbf{TypeScript} for type safety
  \item \textbf{Lucide icons} for clean, consistent iconography
\end{itemize}

\section{Color Palette}

I built the design system around purple accents on a near-black background:

\begin{itemize}
  \item Background: \texttt{\#0a0a0a}
  \item Card: \texttt{\#111111}
  \item Accent: \texttt{\#6d28d9} (violet-700)
  \item Text: \texttt{\#ededed}
\end{itemize}

\section{Key Features}

The site includes animated page transitions, a responsive mobile navigation, and project detail pages with rich content. Everything is statically generated for maximum performance.

\section{Deployment}

Deployed on Vercel with automatic preview deployments for every PR. The site scores 100/100 on Lighthouse across all metrics.
