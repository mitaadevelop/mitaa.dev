# Blog template

Start a post with `npm run new:post can-bus-sniffer "A CAN bus sniffer"` (or `make new-post POST=can-bus-sniffer`). It copies [post.tex](post.tex) to `content/blog/can-bus-sniffer.tex`, fills in the title and today's date, makes the folder `public/blog/can-bus-sniffer/` for images, and marks the post `\draft`: it shows under `npm run dev` and stays out of the production site until you delete that line. Copying the file by hand works too. The file name is the URL: `content/blog/can-bus-sniffer.tex` → `/blog/can-bus-sniffer`.

- **Metadata** goes before `\begin{document}`: `\title`, `\date{YYYY-MM-DD}`, `\excerpt` (card text and meta description), `\tags{A, B}`, and optionally `\subtitle`, `\author`, `\affiliation`, `\version{v2}{YYYY-MM-DD}`, `\kind{Report}`, `\keywords{a, b}`, `\pdf{/docs/blog/<slug>.pdf}`, `\coverimage`, `\xpost`, `\paginate` and `\draft` (dev only).
- **Language**: `\usepackage[dutch]{babel}` (or `\lang{nl}`) gives the post Dutch labels — Figuur, Tabel, Definitie, Inhoud, Pagina 2 van 5. Without it the post is English.
- **Abstract**: an `abstract` before the first `\section` is shown in the header, with the keywords under it.
- **Images** go in `public/blog/<slug>/` and are referenced from the site root: `\includegraphics[width=0.6\textwidth]{/blog/<slug>/scope.png}`.
- **Pages**: with `\paginate{auto}` (the default) a post is split into one page per `\section` only when it has 6+ sections *and* 2000+ words; force it with `always` or `never`. Or decide yourself: `\clearpage` between sections sets the pages, and one page may hold several sections. Pages after `\appendix` are called "Appendices", and their sections are lettered A, B, …
- **References print what LaTeX prints**: `\ref` the number alone (write `Figure~\ref{x}`), `\Cref` / `\autoref` the word and the number, `\cref` the word in lower case, `\eqref` "(3)". Sections, figures, tables, numbered `equation`s, theorems and listings with a `caption=` can all be labelled. Forward references work.
- **What `post.tex` shows**: every feature of the blog in one post, on six pages set with `\clearpage`: text, links, nested lists, a quote with attribution and footnotes; the five callouts; code (`lstlisting`, `minted`, `verbatim`, and a numbered listing); maths (inline, display, a numbered `equation`, `aligned`, matrices, cases, `\ce{}` chemistry and the site's macros `\R \dd \abs \unit …`); the theorem environments with `proof`; figures, two kinds of table, a bar chart, two Mermaid diagrams (a flowchart and a system architecture, drawn by [pele](https://pele.run); the diagram is a `lstlisting[language=mermaid]` in a `figure`, `title=` names it for screen readers, and in the PDF it is printed as source) and every reference command; citations with a bibliography; `\section*`; and an `\appendix` page. Copy it, then delete what the post does not use. A macro outside the supported subset is not translated; `npm run dev` logs it in the terminal.
- **Citations**: `\cite{a,b}` gives "[1, 2]", `\cite[p.~12]{a}` "[1, p. 12]", numbered in `\bibitem` order. The bibliography is printed where `thebibliography` stands. A key that is neither a label nor a bibitem is printed as a visible `[?key]` — search the page for `[?` before publishing.
- **The PDF**: `npm run blog:check <slug>` compiles the post with latexmk (via `content/blog/mitaa.sty`) and checks that every number on the site matches the PDF; `-- --publish` copies the PDF to `public/docs/blog/<slug>.pdf` for `\pdf{}`. `npm run blog:check template` checks this template.
- The full supported subset is in `AGENTS.md`. `content/blog/` holds only your own posts (and `mitaa.sty`); the posts the tests render live in `tests/fixtures/blog/` — `npm run blog:check report-design-showcase` compiles one of them.
- With no posts, `/blog` says "No posts yet." and the home page leaves out its blog section; this template is still served as `/blog/template` under `npm run dev`.
- Check it with `npm run dev` — untranslated macros and environments are logged to the terminal — then `npm test`.

Preview under `npm run dev`: [/blog/template](http://localhost:3000/blog/template) renders [post.tex](post.tex) through the real pipeline.
